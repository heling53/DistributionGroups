# Тесты синхронизации групп рассылки

Прогоняют настоящий `Sync-DistributionGroups.ps1` целиком против каталога Active
Directory, живущего в памяти. Ни домен, ни Exchange не нужны — и сам скрипт при
этом не содержит ни одной правки «под тесты».

## Запуск

```powershell
pwsh -NoProfile -File .\tests\Run-Tests.ps1
```

Работает и в Windows PowerShell 5.1:

```powershell
powershell -NoProfile -File .\tests\Run-Tests.ps1
```

## Как устроено

`tests/modules/ActiveDirectory` и `tests/modules/ImportExcel` — поддельные модули
с теми же именами команд, что и настоящие. Каталог хранится в `$global:ADStore`,
выгрузка 1С — в `$global:ExcelRows`. `Run-Tests.ps1` подставляет папку в начало
`PSModulePath`, поэтому `Import-Module ActiveDirectory` внутри скрипта берёт
подделку, а `#Requires -Modules ActiveDirectory` считается выполненным.

Команды Exchange (`Enable-DistributionGroup`, `Set-DistributionGroup`,
`Disable-DistributionGroup`), `New-PSSession` и транскрипт заглушены прямо
в `Run-Tests.ps1`: функция в сессии перекрывает одноимённый командлет.

Поддельный `Get-ADGroup` намеренно отдаёт **копию** объекта, а не ссылку на него —
как настоящий AD, где полученный объект — снимок на момент запроса. Иначе тесты
не поймали бы ошибки чтения устаревшего состояния.

## Что проверяется

| Тест | Сценарий |
|------|----------|
| 1  | Первичное создание групп, состав, иерархия, `ManagedBy`, адрес, реестр |
| 2  | Повторный прогон ничего не меняет |
| 3  | Полное переименование за день: SID, SamAccountName и адрес сохраняются |
| 4  | Постепенный переезд 4+4+4 из 12: одна группа, состав полон все дни |
| 5  | Разделение отдела надвое: автоматом не переименовывается, уходит человеку |
| 6  | Обычный перевод сотрудника не принимается за переименование |
| 7  | Роспуск отдела: карантин, заморозка состава, удаление по истечении |
| 8  | Дубль из прошлого: вложенность в группу доступа Jira переносится на выжившую |
| 9  | Предохранители: пропажа отдела из выгрузки и пропажа `Department` у людей |
| 10 | Общий предохранитель массового исключения |
| 11 | Возврат к прежнему названию распознаётся по реестру |
| 12 | Защищённая группа не переименовывается, не гасится и не удаляется |
| 13 | Отключённый сотрудник исключается из группы |
| 14 | Сотрудник без табельного номера в `Users.Corp` |
| 15 | Истёкший псевдоним снимается, действующий остаётся |

## Границы стенда

Подделки повторяют поведение AD ровно настолько, насколько его использует скрипт.
Не воспроизводятся: репликация между контроллерами, задержки, права доступа,
ограничения на длину и уникальность `SamAccountName` в масштабе домена,
настоящий разбор LDAP- и AD-фильтров (`Get-ADUser -Filter` понимает только те
два фильтра, которые строит синхронизация). Зелёный прогон означает, что верна
логика принятия решений, а не что домен ответит так же.
